# Offers-Loans-EDA

#### Background
We would like to investigate how loans applications and offers given to the applicants relate to each other, and also predicting how loans can be approved more efficiently. The two datasets consists of basic information such as civil status, age, loan purpose, monthly income, offer disburse and others.

#### Business Questions
- Does age affect loan status?
- Does income affect loan status?
- How does offer amount differ from applied amount?
- Which loan purpose has the highest approval rate?
